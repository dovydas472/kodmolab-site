# kodmolab.lt

Statinė svetainė (GitHub Pages). Jokio serverio, jokių slapukų, analitikos ar išorinių užklausų.

## Struktūra
- `index.html` — Kodmo Lab pagrindinis puslapis
- `auto/index.html` — Kodmo Auto puslapis, `auto/img/` — programos ekranai (WebP)
- `fonts/` — šriftai laikomi čia pat (OFL licencijos `fonts/OFL-*.txt`), Google Fonts nenaudojamas
- `favicon.svg`, `og.jpg`, `auto/og.jpg` — ikonėlė ir dalinimosi vaizdai
- `404.html`, `CNAME` (kodmolab.lt)

## Taisyklės
- Dizainas ir tekstai tvirtinami claude.ai projekte (prototipai), čia tik perkeliami.
- Nedėti analitikos, slapukų, išorinių skriptų ar šriftų iš kitų serverių.
- Ekranų nuotraukos — tik su aiškiai netikrais duomenimis (žr. autoservisas `tools/make_screenshots.py`).
